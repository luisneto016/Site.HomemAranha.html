# Site.HomemAranha.html

Site feito a partir de uma proposta feita por outro grupo da sala de aula. A proposta era fazer um site recomendando livros, séries e filmes, sem qualquer tipo de tema específico. Porém, como tenho uma grande admiração pelo personagem Homem Aranha, decidi fazer o site em sua homenagem, mostrando livros, séries e filmes do Aranha a partir da minha perspectiva e opinião. O site está em uma linguagem mais informal, caso queira as frases mais "rebuscadas", pode simplesmente copiar a programação e trocar de acordo com o seu jeito.
